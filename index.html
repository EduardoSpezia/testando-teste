Documentação técnica do algoritmo monolítico para gestão de ativos industriais em memória.

Sobre o Projeto e Local de Desenvolvimento

Este projeto foi desenvolvido durante as atividades práticas do curso técnico do SENAI, realizado dentro do CentroWEG, unidade educacional integrada ao parque fabril da WEG em Jaraguá do Sul - SC.

Instituição: SENAI / CentroWEG
Localização: Jaraguá do Sul, Santa Catarina
Linguagem: Python 3 (Paradigma Procedural)
Armazenamento: Listas e Dicionários (Em memória)

Arquitetura e Funcionamento do Código

O programa foi estruturado de forma monolítica (em um único arquivo .py) com foco em lógica de programação, manipulação de estruturas de dados nativas e operações básicas de sistema (CRUD).

motores = [] (Array Global)

Funciona como o banco de dados temporário. Armazena dicionários onde cada chave representa uma especificação técnica de placa do motor (Código, Marca, Modelo, Potência em CV, RPM e Tensão).

cadastrar_motor()

Captura os dados via terminal, valida se o código já existe para evitar duplicidade e converte valores numéricos (float para CV e int para RPM) com tratamento de exceções (try/except).

listar_motores() & buscar_motor()

Percorre o array exibindo todos os registros formatados ou filtra resultados utilizando List Comprehension por código ou fabricante.

atualizar_motor() & remover_motor()

Permite editar atributos específicos mantendo os valores atuais caso o usuário pressione Enter em branco, ou excluir um motor da lista pelo índice usando o método .pop().

menu() (Loop Principal)

Controla o fluxo de execução através de um laço while True, mantendo o programa ativo até que o usuário escolha a opção de encerramento.
